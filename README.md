## 📂 هيكل الأكواد البرمجية في هذا المستودع (Code Structure)

يحتوي هذا المستودع على الملفات البرمجية الأساسية للتأكد من سلامة توصيل القطع الإلكترونية الخاصة بك:

* `/01_MPU6050_Raw_Data`: كود قراءة البيانات الخام من مستشعر الاتزان.
* `/02_Brushless_Motor_Test`: كود اختبار المحركات عديمة الفحمات ومعايرة منظم السرعة (ESC).
* `/03_Complete_Drone_Core`: الكود الهيكلي الأساسي للدرون (تجد رابط الكود البرمجي الاحترافي للاستقرار الكامل ومتحكم الـ PID والتحكم بالبلوتوث حصرياً داخل [منصة الأكاديمية](https://academy.sparklabdz.com/)).

## 🛠️ المكونات المستخدمة في المشروع (Hardware Setup)

1.  **لوحة التحكم الرئيسية:** Arduino Uno (أو أي لوحة متوافقة).
2.  **مستشعر الحركة والاتزان:** MPU6050 (Gyroscope + Accelerometer).
3.  **نظام الدفع:** Brushless Motors + Electronic Speed Controllers (ESC).
4.  **هيكل الطائرة والمراوح:** Quadcopter Frame + Propellers.
5.  **وحدة الاتصال:** HC-05 Bluetooth Module.
6.  **مصدر الطاقة:** LiPo Battery (بطارية ليثيوم بوليمر).
