## 📂 الملفات البرمجية المتاحة في هذا المستودع (Repository Files)

تجد في هذا المستودع الملفات البرمجية الأساسية لاختبار القطع والتأكد من سلامة التوصيل قبل الانتقال لمرحلة الطيران:

* `mpu1.ino`: كود قراءة وتصفية بيانات مستشعر الحركة والاتزان MPU6050.
* `esc1.ino`: كود اختبار المحركات عديمة الفحمات (Brushless Motors) ومعايرة منظم السرعة الإلكتروني.
* `bluetouth1.ino`: كود استقبال واختبار إشارات التحكم اللاسلكي عبر وحدة البلوتوث HC-05.
* *(تجد الكود المدمج والكامل للتحكم اللاسلكي الفعلي مع معالجة متحكم الـ Bicopter PID واستقرار الطائرة حصرياً داخل [منصة الأكاديمية](https://academy.sparklabdz.com/)).*

## 🛠️ المكونات المستخدمة في المشروع (Hardware Setup)

1.  **لوحة التحكم الرئيسية:** Arduino Uno.
2.  **مستشعر الحركة والاتزان:** MPU6050 (Gyroscope + Accelerometer).
3.  **نظام الدفع:** Brushless Motors + ESCs.
4.  **وحدة الاتصال اللاسلكي:** HC-05 Bluetooth Module.
5.  **هيكل الطائرة والمراوح:** Quadcopter Frame + Propellers.
6.  **مصدر الطاقة العالية:** LiPo Battery (بطارية ليثيوم بوليمر).
