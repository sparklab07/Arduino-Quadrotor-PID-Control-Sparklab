## 📂 هيكل الأكواد البرمجية المتاحة في هذا المستودع (Code Structure)

يحتوي هذا المستودع على الملفات البرمجية والوحدات الأساسية لبناء الطائرة واختبار قطعها الإلكترونية:

* `/01_MPU6050_Raw_and_Filtered_Data`: كود قراءة وتصفية بيانات مستشعر الحركة والاتزان.
* `/02_ESC_and_Brushless_Motor_Test`: كود اختبار المحركات عديمة الفحمات ومعايرة منظم السرعة الإلكتروني.
* `/03_HC05_Bluetooth_Communication`: كود استقبال واختبار إشارات التحكم اللاسلكي عبر الهاتف.
* *(تجد الكود البرمجي الكامل والمدمج لنظام التحكم اللاسلكي الفعلي مع معالجة متحكم الـ PID واستقرار الطائرة حصرياً داخل [منصة الأكاديمية](https://academy.sparklabdz.com/)).*

## 🛠️ المكونات المستخدمة في المشروع (Hardware Setup)

1.  **لوحة التحكم الرئيسية:** Arduino Uno.
2.  **مستشعر الحركة والاتزان:** MPU6050 (Gyroscope + Accelerometer).
3.  **نظام الدفع:** Brushless Motors + ESCs.
4.  **وحدة الاتصال اللاسلكي:** HC-05 Bluetooth Module.
5.  **هيكل الطائرة والمراوح:** Quadcopter Frame + Propellers.
6.  **مصدر الطاقة العالية:** LiPo Battery (بطارية ليثيوم بوليمر).
